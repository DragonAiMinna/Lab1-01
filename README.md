# Lab1-01：我的开源贡献想法与计划

> 课程实践 · GitHub 入门 · OSS Contribution Plan

## 一、关于我

- 昵称：DragonAiMinna
- 学校：阜阳师范大学 · 计算机专业
- 技术方向：Java Web 开发（Spring MVC / Servlet / Maven / Tomcat / MySQL）、嵌入式与 FPGA（Vivado RTL / LoongArch 平台）、AI 多媒体创作工具链（Seedream / Seedance）
- 竞赛经历：安徽省机器人大赛省级一等奖、睿抗机器人开发者大赛省级三等奖

## 二、我对开源的理解

开源不只是"拿别人的代码用"，而是把课堂作业、课程设计、竞赛代码中**有复用价值的部分**整理出来，反过来回馈社区。
我希望通过这个仓库迈出第一步：学会用 Git / GitHub 进行版本管理、Issue 协作、Pull Request 流程，并逐步从"使用者"成长为"贡献者"。

## 三、我感兴趣并计划参与的方向

结合目前的技术栈，我优先关注以下三类开源项目：

1. **Java Web / 教学示例类项目**
   比如轻量级的图书管理系统、学生信息管理 Demo、Spring Boot 入门脚手架。
   我可以贡献：中文文档补全、示例工程兼容新版 JDK、Bug 修复、README 中的部署说明。

2. **教学与学习资源仓库**
   408 考研笔记、计算机组成原理实验代码、Git / Linux 命令速查表。
   我可以贡献：中文学习笔记整理、练习题补充、LaTeX / Markdown 排版改进。

3. **FPGA / LoongArch 相关教学项目**
   DVI 显示驱动、RISC-V / LoongArch 汇编示例、Vivado 仿真工程模板。
   我可以贡献：中文注释、仿真 Testbench 补充、常见报错排错文档。

## 四、分阶段行动计划

### 阶段 1：本月（熟悉流程）
- [x] 注册 GitHub 账号并配置 SSH / HTTPS 凭证
- [x] 创建第一个公开仓库 `Lab1-01`，提交本份 README
- [ ] 给一个心仪的开源项目点 Star，阅读它的 CONTRIBUTING.md
- [ ] 在熟悉的项目里提第一个 Documentation 类型 Issue

### 阶段 2：本学期（小步贡献）
- [ ] 找一个 Star 数在 100~2000 之间、issue 标记为 `good first issue` 的项目
- [ ] 修复 1~2 个文档错别字或简单 Bug，提交第一个 PR
- [ ] 把自己课程设计中的图书借阅系统整理为开源仓库，补全 README 与部署文档

### 阶段 3：长期（形成个人作品）
- [ ] 持续维护 1 个自己的开源小项目（教学示例 / 学习笔记方向）
- [ ] 争取在一年内完成 3~5 个被合并的 PR
- [ ] 把参与开源的经历整理进简历，作为考研复试与实习面试的项目素材
